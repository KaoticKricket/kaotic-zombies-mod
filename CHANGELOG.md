# Changelog

All notable changes to the Kaotic Zombies Interactive Mod will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [Unreleased]

## [1.0.0] - 2026-07-25

### Added
- TikTok/Tikfinity integration via webhook server
- Creator network access control system
- Six interactive events:
  - zombie_swarm
  - boss_round
  - powerup_drop
  - max_ammo
  - insta_kill
  - double_points
- PowerShell installer for easy setup
- Python Flask bridge server
- RCON protocol integration with BO3
- Creator management CLI tool
- Desktop shortcuts for easy access
- Comprehensive documentation
- Windows installer (Inno Setup)
- Auto-update mechanism for GitHub releases

### Security
- Creator whitelist verification
- RCON password protection
- Webhook authorization
- Network access control

## [0.1.0] - Initial Development

### Added
- Basic GSC mod structure
- RCON event receiver
- Event dispatch system
- Placeholder event handlers
